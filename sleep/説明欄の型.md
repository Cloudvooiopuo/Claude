# 睡眠BGM動画の説明欄の型（動画ごと）

曲はYouTubeオーディオライブラリー（クラシック・穏やか）から選ぶ。
- 曲にCCマーク（クリエイティブ・コモンズ）が付いている → その動画の説明欄に、オーディオライブラリーに出る表記の文をそのまま入れる（条件）
- CCマークが無い → 表記は書かない
- チャンネルのプロフィール（概要）には書かなくてよい。表記は「その曲を使った動画」の説明欄に入れる（10/18 本人の確認）

```
晴れた日の湖と、やさしい風。
遠くの鳥のさえずりとそよ風に、穏やかな音楽を重ねました。
眠る前や、ゆっくり休みたい時にどうぞ。
最後の10分は、音が少しずつ小さくなります。

（CCマークの曲を使った時だけ、ここにオーディオライブラリーの表記の文を貼る）

#睡眠用BGM #リラックス #クラシック #自然音 #作業用BGM
```
