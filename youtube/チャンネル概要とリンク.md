# YouTubeチャンネルの概要とリンク（Amazonアソシエイト用）

## 1. アソシエイトにチャンネルを登録する（本人）
Amazonアソシエイト管理画面 → 右上のメールアドレス →「アカウント設定」→「Webサイト情報の編集」
→「Webサイトとモバイルアプリ」にチャンネルのURL（https://www.youtube.com/@…）を足して保存。

## 2. チャンネルの概要に入れる文（コピーして使う）
YouTube Studio →「カスタマイズ」→「基本情報」→「説明」

暮らし・おでかけ・メディアの「ちょっとラクになるコツ」を、毎日18時にショート動画で出しています。
保存して、あとで見返してね。

商品紹介の回は #PR を付けています。紹介した物はこのチャンネルのリンクから見られます。
Amazonのアソシエイトとして、カフェと旅と売れ筋メモは適格販売により収入を得ています。

※ナレーションはVOICEVOX、写真はWikimedia Commons（CC0／パブリックドメイン）を使っています。

## 3. チャンネルのリンク
同じ「基本情報」→「リンク」→「リンクを追加」
- タイトル：紹介した物（Amazon）
- URL：https://linktr.ee/ziyunayiteng （Instagramのプロフィールと同じリンク集。10/17本人から。中にAmazon売れ筋ランキングへのアソシエイトリンクがある）

## 4. 動画の文
今の「紹介した物はプロフィールのリンクから」のままでよい（YouTubeではチャンネルのページがプロフィールにあたる）。
InstagramとTikTokと同じ文で1回に予約できるので、文は分けない。
